# Doggle — A Dog Searcher 🐶

A responsive, single-page dog breed image searcher built with **Vite, React, and CSS**. Search a breed to discover four random dog photos using the [Dog CEO API](https://dog.ceo/dog-api/).

## Features
- Search dog breeds using lowercase breed names
- Displays four random photos for a valid breed
- Loading, empty, and error states
- Clear search and return to the welcome state
- Responsive layout for mobile, tablet, and desktop
- Single page — no routing library required

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite.

## Production build
```bash
npm run build
npm run preview
```

## Example breeds
Try `husky`, `pug`, `beagle`, `labrador`, or `germanshepherd`.

## Tech stack
- React
- Vite
- JavaScript (JSX)
- CSS
- Dog CEO API
